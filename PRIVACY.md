# Privacy Policy

This policy covers the Olostep plugin for Dify.

## Data sent to Olostep

When you use a tool, the plugin sends the tool inputs (URLs, search queries, questions and options) to the Olostep API at `https://api.olostep.com` over HTTPS. Your Olostep API key is sent in the `Authorization` header. Olostep uses these inputs to fetch the requested web pages or search results and returns them to Dify.

Olostep's handling of this data is described in the [Olostep privacy policy](https://www.olostep.com/privacy-policy).

## Data stored by the plugin

The plugin does not collect, store or log your inputs, results or API key. It does not send data to any third party other than the Olostep API, and it includes no analytics or telemetry.

Dify stores your API key as a secret credential and may keep workflow inputs, outputs and logs according to your Dify workspace settings. This is handled by Dify, not by the plugin.

## Your responsibilities

Only scrape, crawl or search content you are allowed to access. Do not send passwords, access tokens or other sensitive personal data in tool inputs. To stop the plugin from using your account, remove the credential in Dify or revoke the key in the [Olostep dashboard](https://www.olostep.com/dashboard).
